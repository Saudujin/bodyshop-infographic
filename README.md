# The Body Shop International - Interactive Infographic

An interactive, visually engaging infographic showcasing the revolutionary business model of The Body Shop International (1976-1991).

## 🌟 Overview

This project transforms a Harvard Business School case study into a modern, responsive web infographic that tells the story of Anita Roddick's groundbreaking approach to cosmetics retail.

## ✨ Features

- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging motion effects using Framer Motion
- **Professional Styling**: Modern UI with Tailwind CSS
- **Interactive Elements**: Hover effects and smooth transitions
- **Comprehensive Content**: Complete case study information beautifully presented

## 📊 Content Sections

1. **Founder Story**: Anita Roddick's background and vision
2. **Unconventional Approach**: Products, Marketing, and Retail strategies
3. **Phenomenal Growth**: Timeline from 1976 to 1991
4. **Three Pillars**: Environmental, Social Responsibility, and Trade Not Aid
5. **Outstanding Performance**: Key financial metrics and comparisons
6. **Challenges Ahead**: Internal and external challenges faced

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Saudujin/bodyshop-infographic.git

# Navigate to project directory
cd bodyshop-infographic

# Install dependencies
npm install
# or
pnpm install

# Start development server
npm run dev
# or
pnpm run dev
```

### Build for Production

```bash
npm run build
# or
pnpm run build
```
